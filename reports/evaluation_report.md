# Обнаружение компонентов счетчиков электроэнергии и локализация области показаний

## Обзор

Данный проект посвящен автоматическому обнаружению и локализации компонентов счетчиков электроэнергии с использованием моделей компьютерного зрения.

## Модели

### YOLO1: Обнаружение компонентов счетчика

Обнаруживает:

* счетчик
* цифровой дисплей
* аналоговый счетный механизм

Классы:

| ID | Класс           |
| -- | --------------- |
| 0  | meter           |
| 1  | digital_display |
| 2  | analog_register |

### YOLO2: Обнаружение области показаний

Обнаруживает:

* область показаний

Классы:

| ID | Класс        |
| -- | ------------ |
| 0  | reading_area |

## Обучение

### Обучение YOLO1

python -m src.detection.train_meter_screen --config configs/yolo_meter_screen.yaml
### Обучение YOLO2

python -m src.detection.train_reading_area --config configs/yolo_reading_area.yaml
## Инференс

### Визуализация результатов

yolo task=obb mode=predict \
model=weights/best.pt \
source=datasets/images/test \
save=True
### Оценка на тестовом наборе

yolo task=obb mode=val \
model=weights/best.pt \
data=data.yaml \
split=test
## Оценка

Оценка проводилась на следующих выборках:

* test split
* analog_test split

Используемые метрики:

* Precision
* Recall
* mAP50
* mAP50-95

Пороги Confidence и IoU были подобраны экспериментально путем оценки качества модели при различных значениях порогов.
